# BALOCH AI Video Studio

A front-end prototype inspired by the supplied reference screenshots, using original BALOCH AI branding and a similar studio-style layout.

## Run
Open `index.html` in a modern browser.

## Included
- Dark cyber/neon BALOCH AI UI
- Sidebar: media, characters, scenes, tools, generated videos
- Video prompt workspace
- Provider/model selector
- Aspect ratio and generation controls
- Credits demo
- Admin panel mockup for user approvals, credits, and provider routing
- Supplied branding images in `assets/`

## Important
This is a front-end prototype. Real video generation, authentication, user approval, credits accounting, and provider integrations require a secure backend.

For provider integrations, use official APIs/OAuth or other authorized integrations. Keep API keys/tokens on the server; never put provider passwords or secret keys in browser JavaScript.
